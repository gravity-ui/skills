# Мониторинг CPU

`npm install`, `npm run dev` — запуск страницы. `npm run build` — проверка TypeScript и production-сборка. `npm test` — тесты буфера и жизненного цикла компонента.

`CpuChart` использует Canvas (Yagr/uPlot), подсказки при наведении, выделение диапазона мышью и сброс масштаба. Тема берётся из Gravity UI ThemeProvider; по умолчанию она следует системной настройке. Размер отслеживается через ResizeObserver.

## Подключение метрик

В репозитории нет сервера метрик: страница явно показывает демонстрационный поток из 43 200 точек, с новым значением каждые две секунды. Замените `demoCpuSource` в `App.tsx` адаптером `CpuSource` из `src/cpu-data.ts`:

- `getHistory()` синхронно возвращает уже загруженную историю (или пустой массив).
- `subscribe(listener)` передаёт упорядоченные пакеты `{timestamp, value}` и возвращает функцию освобождения подписки. Асинхронную начальную загрузку также можно передать через listener, перед последующими live-пакетами.
- `timestamp` — Unix-время в миллисекундах; `value` — загрузка от 0 до 100 либо `null` для пропуска. История и последующие пакеты идут в порядке возрастания времени. Повтор последнего timestamp заменяет его значение; более старые, будущие и некорректные точки игнорируются.
- Сохраняйте ссылку на объект источника между React-рендерами; его замена закрывает старую подписку и создаёт новый график.

Буфер хранит последние 24 часа, максимум 100 000 точек. При превышении лимита вытесняются самые старые точки: для потока с большей плотностью увеличьте лимит в `CpuBuffer` или агрегируйте данные на сервере. Копирование массивов и обновление Canvas объединяются через таймер и requestAnimationFrame (не чаще 10 раз в секунду); отдельные сообщения не вызывают React-рендеры. Выбранный масштаб сохраняется при обновлении данных. После сброса график снова следует текущему времени.

При размонтировании закрывается подписка, отменяются таймеры и animation frames, отключается ResizeObserver и вызывается `Yagr.dispose()`. Тесты проверяют в том числе повторное монтирование React StrictMode, первую точку после пустой истории и сохранение диапазона.
