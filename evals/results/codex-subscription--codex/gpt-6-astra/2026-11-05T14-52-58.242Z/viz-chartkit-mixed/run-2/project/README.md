# Pulse

Адаптивная демонстрационная панель продаж и мониторинга на React + TypeScript.

```sh
npm install
npm run dev
npm run build
```

## Единый API визуализации

`src/components/Visualization.tsx` экспортирует компонент `Visualization`:

```tsx
<Visualization
  mode="sales" // или "monitoring"
  series={[
    {
      id: "revenue",
      label: "Выручка",
      color: "#9276df",
      data: [
        { x: 1750032000000, y: 120000 },
        { x: 1750118400000, y: 145000 },
      ],
    },
  ]}
  unit="₽"
  formatX={(timestamp) => new Date(timestamp).toLocaleDateString("ru-RU")}
  formatY={(value) => value.toLocaleString("ru-RU")}
/>
```

`x` — временная метка в миллисекундах, `y` — числовое значение. Серии должны иметь совпадающие временные отметки, отсортированные по возрастанию. Необязательный `dashed` задаёт пунктирную линию.

Два собственных движка используют одинаковый контракт `ChartProps`:

- `SalesEngine` — SVG, сглаженные линии, заливка, сравнение, подсказки.
- `MonitoringEngine` — Canvas с учётом pixel ratio, ResizeObserver, подсказками и масштабированием временного окна.

Каждый движок подключён через отдельный `React.lazy(() => import(...))`. Vite выпускает независимые чанки; невыбранный движок не загружается. `Suspense` показывает загрузку, error boundary обрабатывает ошибку загрузки.

В панели доступны периоды 7/14/30 дней, фильтрация источников, сравнение, экспорт текущих серий в CSV, смена демопространства и настройки автообновления. Мониторинг содержит 3 600 точек на серию и обновляется раз в 15 секунд. Все данные демонстрационные; внешние сервисы не подключены.
