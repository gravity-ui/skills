# Мониторинг CPU

React + TypeScript, Gravity UI и Yagr (Canvas/uPlot). Запуск: `npm ci`, `npm run dev`.
Проверки: `npm test`, `npm run build`. Браузерная проверка: `npx playwright install --with-deps chromium`, затем `npm run test:e2e`.

`CpuChart` принимает стабильный объект `CpuSource` из `src/cpuMetrics.ts`:

```tsx
const source: CpuSource = {
  getHistory: () => preloadedHistory,
  subscribe: (listener) => metricsStream.subscribe(listener),
};

<CpuChart source={source} />;
```

Историю нужно предварительно загрузить из вашего API. `subscribe` передаёт пакеты `{timestamp, value}` в хронологическом порядке и возвращает функцию отписки. `timestamp` — Unix-время в миллисекундах, `value` — загрузка от 0 до 100 или `null` для отсутствующего измерения. Повтор последнего timestamp заменяет значение; более старые и некорректные измерения игнорируются. При смене источника создаётся новая подписка.

В приложении подключён явно обозначенный демонстрационный адаптер: около 43 тысяч измерений за 24 часа с обновлением каждые 2 секунды. Серверного источника в каркасе проекта нет.

История хранится в кольцевом буфере с ограничением 100 000 точек и скользящим окном 24 часа. Более высокая частота требует предварительной агрегации в источнике либо изменения лимита. В React передаются только сводные показатели. Пакетные обновления графика ограничены четырьмя в секунду; при отсутствии новых данных окно времени сдвигается раз в секунду. Пауза останавливает отображение, сохраняя приём в ограниченный буфер. Масштаб, выбранный выделением области, сохраняется при поступлении данных.

Тема берётся из Gravity UI `ThemeProvider` и обновляется через `setTheme` без пересоздания графика. Ширину и высоту отслеживает `ResizeObserver`, изменение размера объединяется через `requestAnimationFrame`. При размонтировании отменяются кадр, таймер и подписка, отключается observer и вызывается `dispose()`.

Для обновления времени используется публичный `chart.config.timeline` и `setSeries('cpu', ...)`: в Yagr 5.3.1 перегрузка `setSeries(timeline, series, {incremental: false})` пересоздаёт uPlot. Версия библиотеки зафиксирована; при обновлении следует проверить это поведение. Переход от пустого набора к данным может потребовать однократного восстановления внутреннего uPlot средствами Yagr.
