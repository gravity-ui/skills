# Pulse: мониторинг CPU

`npm run dev` запускает страницу, `npm run build` проверяет TypeScript и собирает приложение, `npm test` запускает тесты.

График на Yagr/uPlot отображает 43 201 точку за последние сутки с шагом 2 секунды. Он использует Canvas, обновляет существующую серию по ID, объединяет перерисовки через `requestAnimationFrame`, сохраняет выделенный интервал при обновлениях и отслеживает размер контейнера через `ResizeObserver`. Тема берётся из `ThemeProvider` Gravity UI; исходно используется системная тема.

Доступны периоды 1/6/12/24 ч, подсказки при наведении, увеличение выделением, сброс двойным нажатием или кнопкой, пауза, разворачивание графика, порог 80% и экспорт выбранного периода в CSV. Статистика карточек относится к периоду кнопок; выделение мышью изменяет только масштаб графика.

В исходном проекте нет API метрик, поэтому страница явно использует демонстрационный поток. Сведения о сервере также демонстрационные. Для реального подключения замените `createDemoSource` в `src/App.tsx` адаптером `CpuSource` из `src/telemetry.ts`. Он должен возвращать кешированный снимок с возрастающими Unix timestamp в **миллисекундах**, выровненными массивами `timeline` и `values` (CPU в процентах), статистикой и временем обновления. `subscribe` уведомляет об изменении снимка и возвращает функцию отписки. Сетевое соединение следует закрывать после последней отписки. `CpuHistory` предоставляет ограниченный суточный буфер для источников с шагом не чаще 2 секунд.

При размонтировании график отключает observer, обработчики событий и подписку, отменяет запланированные кадры и вызывает `Yagr.dispose()`. Демонстрационный таймер работает только при наличии подписчиков; на паузе и после размонтирования он остановлен. В скрытой вкладке перерисовки пропускаются, а при возвращении выводится последний снимок.
