# Pulse — мониторинг CPU

React + TypeScript + Gravity UI. График использует Canvas-рендерер
[@gravity-ui/yagr](https://github.com/gravity-ui/yagr) на базе uPlot.

## Запуск и проверки

```sh
npm ci
npm run dev
npm run build
npm test
npx playwright install --with-deps chromium
npm run test:e2e
```

## Данные

API и поток серверных метрик в исходном проекте отсутствуют. На странице это явно
обозначено: используется детерминированный демопоток с интервалом 2 секунды,
43 201 точкой за сутки и тремя демонстрационными серверами.

Для подключения API замените `createDemoHistory` и эффект таймера в `MonitoringPage`
на загрузку снимка истории и подписку на WebSocket/SSE. При смене сервера закрывайте
старую подписку и отменяйте запрос через AbortController; возвращайте функцию
отписки из эффекта. Передавайте в `CpuChart` новые неизменяемые снимки `CpuHistory`:

```ts
interface CpuHistory {
  timestamps: number[]; // epoch milliseconds, по возрастанию, без дубликатов
  values: number[]; // соответствующие значения CPU от 0 до 100
}
```

`appendCpuSample` проверяет входящие точки и удаляет данные старше суток. Для частых
потоков собирайте входящие точки в пакет перед публикацией снимка в React.
Компонент объединяет изменения графика через requestAnimationFrame; несколько
изменений за кадр приводят к одному обновлению. Смена периода ограничивает ось X,
исходные точки остаются доступны при увеличении. Шкала Y всегда 0–100%.

## Поведение и жизненный цикл

- Подсказка по наведению, выделение мышью для увеличения, двойной клик или кнопка
  для сброса. Пользовательский масштаб сохраняется при обновлениях.
- Периоды 1/6/24 часа, переключение сервера, пауза, скрытие серии и экспорт CSV
  выбранного периода. CSV содержит исходные точки и даты ISO 8601 в UTC.
- Светлая/тёмная тема берётся из `useThemeType`; изначально следует системе,
  переключается кнопкой. Тема обновляется через `setTheme` на том же экземпляре.
- Размер следует контейнеру через ResizeObserver. Размеры и данные объединяются
  в кадры, маркеры для каждой точки отключены.
- Используется обновление существующей серии: полный overload `setSeries` с
  `incremental: false` в Yagr 5.3.1 пересоздаёт внутренний uPlot.
- При размонтировании вызывается `dispose()`, отключается ResizeObserver,
  удаляется обработчик двойного клика, отменяются кадры и таймеры. Проверено с
  повторным монтированием эффектов в React StrictMode.

Unit-тесты проверяют границы суток, корректность статистик, целостность истории
и обработку ошибочных/повторных точек. Браузерные тесты проверяют поток, сохранение
Canvas, тему, zoom, CSV, адаптивность, пустые данные и освобождение ресурсов.
