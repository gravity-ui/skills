# Мониторинг CPU

```sh
npm install
npm run dev
npm test
npm run build
```

Страница показывает демонстрационные метрики: 43 201 точка за сутки, новое измерение
каждые 2 секунды. Реальный API в исходном проекте отсутствует.

Для подключения метрик передавайте в `CpuChart` обновляемый `data: CpuData`:

```tsx
<CpuChart data={{timeline: timestampsMs, values: cpuPercentages}} />
```

`timeline` — возрастающие Unix timestamps в миллисекундах; `values` — значения
от 0 до 100 или `null` для пропусков. Массивы должны иметь одинаковую длину.
При обновлении передавайте новый объект снимка; храните только последние сутки.
`appendCpuSample` добавляет измерение и удаляет устаревшие точки без изменения
предыдущего снимка. Отписку от реального потока необходимо вернуть из эффекта
подключения, аналогично очистке демонстрационного таймера в `App`.

Yagr рисует график на Canvas без постоянных маркеров. Экземпляр сохраняется между
обновлениями данных и темы. `requestAnimationFrame` объединяет обновления и resize;
при размонтировании кадр отменяется, `ResizeObserver` отключается, вызывается
`dispose()`. Тема берётся из Gravity UI `ThemeProvider`.

Наведение показывает время и загрузку. Выделение мышью увеличивает участок;
двойной щелчок или кнопка «Все 24 часа» возвращают суточное окно с автопрокруткой.
При увеличении выбранный интервал сохраняется во время поступления новых данных.
