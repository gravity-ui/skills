# Pulse

Единый виджет аналитики продаж и мониторинга на React + TypeScript.

```sh
npm install
npm run dev
npm run build
```

## API виджета

```tsx
import { VisualizationWidget, type ChartSeries } from "./src/widget";

const series: ChartSeries[] = [
  {
    id: "revenue",
    name: "Выручка",
    color: "#789c47",
    points: [
      { timestamp: Date.UTC(2026, 9, 1), value: 42000 },
      { timestamp: Date.UTC(2026, 9, 2), value: 48000 },
    ],
  },
];

<VisualizationWidget
  mode="sales" // 'sales' | 'monitoring'
  series={series}
  unit="₽"
  height={320}
  zoom={1}
/>;
```

`timestamp` — миллисекунды Unix. Точки должны идти по возрастанию времени. Серии мониторинга используют общую временную сетку: одинаковое количество точек и совпадающие timestamps. `dashed` задаёт пунктирную линию. `zoom` — коэффициент приближения последнего участка мониторинга (1 — весь период).

Оба движка используют `ChartRendererProps`. `React.lazy` и динамические `import()` создают независимые чанки для адаптеров вместе с их зависимостями: Highcharts для продаж, uPlot для плотных временных рядов. Неактивный движок не запрашивается до переключения режима. `Suspense` показывает состояние загрузки, error boundary обрабатывает ошибку загрузки, пустые данные имеют отдельное состояние. При смене режима график уничтожается; `ResizeObserver` и таймеры очищаются.

В демо работают выбор периода и канала, сравнение, масштабирование и выделение участка мониторинга, автообновление синтетических данных, разворачивание графика и экспорт CSV. Для интеграции с реальными источниками передавайте данные через `series`; сетевого источника в демо нет.

Браузерные проверки: `npx playwright install chromium`, затем `npm run test:e2e`.
