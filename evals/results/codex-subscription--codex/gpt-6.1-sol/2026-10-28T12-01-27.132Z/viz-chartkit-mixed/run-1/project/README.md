# Pulse

Адаптивный дашборд с единым виджетом для аналитики продаж и плотных временных рядов мониторинга. Данные демонстрационные и генерируются локально; внешние сервисы не подключаются.

```sh
npm install
npm run dev
npm run build
```

## Единый API виджета

`src/components/VisualizationWidget.tsx` экспортирует `VisualizationWidget`, `VisualizationWidgetProps`, `ChartMode`, `ChartPoint` и `ChartEngineProps`.

```tsx
<VisualizationWidget
  mode={mode} // 'sales' | 'monitoring'
  onModeChange={setMode}
  data={points} // Array<{ time: number; value: number; comparison: number }>
  periodLabel="Этот месяц"
  onExport={exportCsv}
  onRefresh={refresh}
/>
```

`time` — Unix timestamp в миллисекундах. В режиме продаж `value` и `comparison` выражены в рублях, в режиме мониторинга — в миллисекундах. Приложение управляет данными и выбранным режимом, виджет — отображением рядов, детализацией и разворачиванием.

Оба движка имеют единый интерфейс `ChartEngineProps` и загружаются через `React.lazy` и динамический `import()`. Recharts используется для SVG-графика продаж с подсказками; uPlot — для Canvas-графика мониторинга с 3 600 точками, выделением диапазона и сбросом масштаба двойным щелчком. Неактивный движок не загружается. Оба движка освобождают ресурсы при размонтировании; uPlot также отключает ResizeObserver.

Доступны выбор периода, сравнение рядов, экспорт CSV, обновление данных, приостановка мониторинга и полноэкранный график. Дополнительные экраны показывают локальные источники, события и настройки. Изменения демо-источников и настроек живут в текущей сессии страницы.

## Проверка

```sh
npx playwright install chromium
npm run test:e2e
```

Браузерные проверки используют production-сборку и проверяют ленивую загрузку движков по сетевым запросам, переключение режимов, периоды, видимость рядов, содержимое CSV, локальные источники, настройки и отсутствие горизонтального переполнения на мобильном экране.
