# Простор

Небольшое приложение для проектов, заметок и идей на React, TypeScript и Vite.

## Запуск

```sh
npm install
npm run dev
```

## Возможности

- Три страницы: обзор, проекты и заметки. Навигация поддерживает прямые ссылки и кнопки браузера «Назад» и «Вперёд».
- Светлая и тёмная темы с сохранением выбора.
- Создание проектов, просмотр прогресса, отметка выполненных задач, фильтры и поиск.
- Создание, редактирование, поиск и удаление заметок.
- Адаптивное меню и интерфейс для телефона.
- Диалоги с управлением с клавиатуры; Escape закрывает окно, Ctrl/⌘ + K открывает поиск на страницах проектов и заметок.

Проекты, заметки и тема сохраняются в localStorage этого браузера. Сервер и аккаунт для работы не нужны. При первом запуске отображаются демонстрационные данные.

## Проверка сборки

```sh
npm run build
```

Шрифт Golos Text и фотография загружаются из локальных файлов. Лицензия шрифта находится в `public/fonts/OFL.txt`. Фотография: [Unsplash](https://images.unsplash.com/photo-1497215728101-856f4ea42174).
