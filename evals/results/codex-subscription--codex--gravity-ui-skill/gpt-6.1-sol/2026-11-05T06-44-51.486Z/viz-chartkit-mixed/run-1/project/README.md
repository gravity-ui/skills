# Пульс — виджет визуализации

Один `VisualizationWidget` с двумя режимами:

- `sales` — линейный график `@gravity-ui/charts`;
- `monitoring` — плотный временной ряд `@gravity-ui/yagr`, до 14 400 точек на серию в демо.

Оба режима используют `ChartKit`. Плагины зарегистрированы в `src/lib/chartkit.ts`; их встроенные `React.lazy` загружают движки по требованию. Импорты типов в адаптерах не включают библиотеки в основной JS.

```tsx
<VisualizationWidget
  mode={mode}
  onModeChange={setMode}
  data={{
    unit: '₽',
    timeline: [1793520000000, 1793606400000],
    series: [{id: 'revenue', name: 'Выручка', values: [12000, 14500]}],
  }}
  range="7"
  onRangeChange={setRange}
  loading={false}
  error={undefined}
  onRefresh={refetch}
  updatedAt={new Date()}
/>
```

`VisualizationData` — общий формат: UTC timestamps в миллисекундах, отсортированные по возрастанию; массив значений каждой серии соответствует timeline. `null` означает пропущенное измерение. `comparison: true` задает серию сравнения. Режим и период контролируются родителем; при изменении периода он передает новые данные. Периоды продаж: `7`, `30`, `90` дней; мониторинга: `1`, `6`, `24` часа.

Виджет поддерживает загрузку, ошибку с повтором, пустой набор, отключение всех серий, экспорт CSV, подсказки. Мониторинг позволяет выделять область для увеличения. Приложение использует демонстрационные данные: обновление повторно отмечает время получения того же набора; подключение backend выполняется через `data` и `onRefresh`.

Проверки: `npm run build` (TypeScript и production build), `npx vitest run` (адаптеры, выравнивание плотных данных, сводные значения и CSV). Vite сохраняет `dist/.vite/manifest.json` для проверки отдельных динамических чанков.

Визуальная проверка вручную: светлая/темная тема, ширины 375 и 1400 px; загрузка, ошибка и отсутствие данных. Проверка типов и сборка не подтверждают внешний вид в браузере.
