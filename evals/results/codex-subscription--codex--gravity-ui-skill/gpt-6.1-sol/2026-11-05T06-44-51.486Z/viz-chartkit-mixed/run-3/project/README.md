# Пульс · виджет визуализации

Один виджет на Gravity UI ChartKit с двумя лениво загружаемыми движками:

- `sales` — линейный график Gravity Charts, периоды 7 / 30 / 90 дней.
- `monitoring` — плотный временной ряд YAGR, периоды 1 / 6 / 24 часа, шаг 6 секунд.

## Запуск и проверка

```sh
npm install
npm run dev
npm run build
npx vitest run
```

## Единый API

```tsx
import {VisualizationWidget} from './src/components/VisualizationWidget';

<VisualizationWidget
  mode="sales" // либо "monitoring"
  data={{timeline: [timestampMs], current: [100], previous: [90]}}
  compare={true}
  markers={false}
/>
```

`timeline` содержит возрастающие UTC timestamp в миллисекундах. Массивы значений должны иметь одинаковую длину с `timeline`. `previous` совмещён по времени с текущим периодом; `markers` применяется к продажам. Компонент требует `ThemeProvider` и стили UIKit, подключённые в приложении.

Плагины зарегистрированы один раз. Их дескрипторы используют `React.lazy`: JS и CSS соответствующего движка загружаются при первом открытии его режима. Состояния загрузки, ошибки с повтором и отсутствия данных предусмотрены в виджете.

Интерфейс поддерживает сравнение, CSV с исходными точками выбранного периода, светлую и тёмную темы, настройки маркеров и имитацию поступления наблюдений. Данные демонстрационные и генерируются локально, сервер не требуется. История заканчивается 30 сентября 2026, автообновление продолжает временной ряд относительно этой даты.

Типизация и сборка не проверяют внешний вид. Для ручной проверки: оба режима в светлой и тёмной теме на ширине 375 и 1400 px, отсутствие горизонтального скролла, подсказки, диалоги, экспорт и состояния загрузки / ошибки / пустых данных.
