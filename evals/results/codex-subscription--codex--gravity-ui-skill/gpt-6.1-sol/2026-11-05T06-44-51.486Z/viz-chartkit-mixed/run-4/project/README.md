# Pulse

Один виджет Gravity UI для линейного графика продаж и плотного ряда мониторинга.

```tsx
import {VisualizationWidget} from './src/VisualizationWidget';

<VisualizationWidget
  mode="sales" // либо "monitoring"
  series={[{
    id: 'revenue',
    name: 'Выручка',
    color: 'var(--g-color-text-brand)',
    data: [{x: 1790000000000, y: 120}, {x: 1790086400000, y: 145}],
  }]}
  height={310}
/>
```

Оба режима используют `VisualizationWidgetProps`: `mode`, `series`, `height`,
`loading`, `error`, `onRetry`. Время `x` всегда задаётся в Unix milliseconds.
Компонент самостоятельно адаптирует единый формат к Gravity Charts и Yagr;
импортировать движки вызывающему коду не нужно. Приложение должно быть обёрнуто
в UIKit `ThemeProvider` и подключать стили UIKit, как в `src/main.tsx`.

`src/chartRegistry.ts` регистрирует ленивые плагины ChartKit через `React.lazy`
и `import()`. Даже точка входа gravity-charts загружается динамически, поскольку
она реэкспортирует движок. Код и CSS Yagr загружаются при первом открытии
мониторинга. Повторные переключения используют загруженные модули.

Интерфейс демонстрирует выбор периода, сравнение продаж, скрытие серий,
автообновление мониторинга каждые 5 секунд, настройки высоты и экспорт видимых
серий в CSV. Данные демонстрационные, генерируются локально. Обновление плотного
ряда сохраняет значения для пересекающихся временных отметок. После скрытия всех
серий отображается пустое состояние. Предусмотрены загрузка и ошибки ChartKit.

Команды: `npm run dev`, `npm run build` (typecheck + production build), `npm test`.

Автоматические проверки не оценивают внешний вид. Для визуальной приёмки:
светлая/тёмная тема, ширина 375/1400 px, переключение обоих режимов, пустое
состояние при скрытии серий, состояние загрузки при ограничении сети и ошибка
загрузки чанка.
