# Пульс — виджет аналитики

Один виджет с режимами продаж и плотного мониторинга на Gravity UI.

```sh
npm install
npm run dev
npm test
npm run build
```

## Единый API

```tsx
import {VisualizationWidget} from './src/components/VisualizationWidget';

<VisualizationWidget
  mode="sales" // или "monitoring"
  series={[{
    id: 'revenue',
    name: 'Выручка',
    color: 'var(--g-color-text-positive)',
    points: [
      {timestamp: 1793318400000, value: 100000},
      {timestamp: 1793404800000, value: 140000},
    ],
  }]}
/>
```

`timestamp` — Unix-время в миллисекундах. Точки упорядочены по времени; в режиме мониторинга ряды используют общую временную сетку. `comparison: true` обозначает пунктирный ряд продаж. Есть общие свойства `loading`, `error`, `onRetry`.

ChartKit маршрутизирует `sales` в `gravity-charts`, а `monitoring` в `yagr`. Оба плагина зарегистрированы через `React.lazy` и динамические импорты: входные модули плагинов и движки загружаются при первом открытии соответствующего режима. Типы импортируются через `import type`.

Приложение добавляет периоды, сравнение, переключение рядов, CSV, автообновление каждые 5 секунд, разворачивание и светлую/тёмную тему. Данные демонстрационные; мониторинг генерируется локально. При сдвиге окна значения уже существующих точек сохраняются. CSV экспортирует отображаемые ряды с временем UTC.

## Проверка

Тесты проверяют адаптацию одного формата данных к обоим движкам, ленивую регистрацию, состояния загрузки/ошибки/пустых данных и временную согласованность мониторинга. `npm run build` выполняет TypeScript и production-сборку.

Браузерная проверка не выполнялась. Для визуальной приёмки: проверить оба режима в светлой и тёмной теме на ширине 375 и 1400 px, отсутствие горизонтального переполнения, подсказки графиков, CSV и разворачивание. Пустое состояние доступно при отключении обоих рядов мониторинга. Состояния загрузки и ошибки проверяются через соответствующие свойства виджета. Проверка типов не подтверждает вёрстку и контраст.
