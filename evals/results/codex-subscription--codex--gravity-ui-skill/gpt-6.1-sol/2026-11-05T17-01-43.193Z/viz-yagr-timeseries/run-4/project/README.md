# Мониторинг CPU

```sh
npm install
npm run dev
```

Страница показывает **демонстрационные** данные: около 43 200 измерений за последние 24 часа, с обновлением каждые 2 секунды. Кнопка темы переключает светлое и тёмное оформление; начальная тема соответствует системе.

`CpuChart` использует `@gravity-ui/yagr` 5.3.1. Наведение показывает время и значение; выделение мышью приближает участок и отключает автослежение. Кнопки периода и сброс масштаба возвращают автослежение. Выключенное автослежение сохраняет выбранный диапазон, пока данные продолжают поступать.

## Подключение метрик

Передайте стабильный объект `CpuDataSource` в `CpuChart` вместо `createDemoCpuSource()` из `App.tsx`:

```tsx
<CpuChart source={cpuSource} />
```

Контракт определён в `src/cpu-data.ts`:

- `loadHistory(signal)` загружает историю за сутки; запрос должен поддерживать переданный `AbortSignal`.
- `subscribe(onSamples, onError)` передаёт новые точки пакетами и возвращает функцию закрытия соединения и удаления обработчиков. Ошибки соединения передаются в `onError`.
- Точка имеет вид `{timestamp: 1793894400000, value: 42.5}`: Unix-время **в миллисекундах**, загрузка от 0 до 100 процентов. `null` обозначает разрыв данных.
- История и поток идут по возрастанию времени. Повтор последней временной отметки заменяет её значение; запоздалые точки и некорректные значения отбрасываются.

Подписка открывается до загрузки истории; поступившие во время запроса точки сохраняются в ограниченном буфере и объединяются с историей. При повторной попытке соединение открывается заново.

Данные хранятся вне React в кольцевом буфере: добавление точки занимает O(1), память ограничена последними **100 000 точками** и суточным окном. При более высокой частоте измерений источник должен агрегировать данные, чтобы сохранить покрытие всех суток. Снимок для графика создаётся максимум 4 раза в секунду, отрисовка привязана к `requestAnimationFrame`. Экземпляр Yagr и внутренний uPlot сохраняются при обновлении данных, масштаба и темы. При размонтировании отменяются запрос, подписка, таймеры и кадр анимации; `ResizeObserver` отключается, Yagr освобождается через `dispose()`.

## Проверки

```sh
npm test
npm run build
```

Тесты проверяют суточное окно, ограничение памяти, разрывы и повторы точек, пакетные обновления, сохранение масштаба, смену темы, состояния загрузки/ошибки/отсутствия данных и очистку ресурсов, включая React StrictMode. В тестах компонента рендерер Yagr заменён тестовым объектом; Canvas и визуальное оформление не проверяются.

Для ручной проверки: светлая и тёмная темы, ширина около 375 и 1400 px, подсказки и масштабирование, загрузка/ошибка/пустая история с реальным источником.
