# График CPU

`CpuLoadChart` использует Canvas через `@gravity-ui/yagr` и принимает `source: CpuSource`.
На странице подключён `demoCpuSource`: синтетическая история примерно из 43 200 точек
с обновлением каждые две секунды. Реального API в заготовке проекта нет.

Для подключения метрик реализуйте интерфейс из `cpuData.ts`:

- `loadHistory(from, to, signal)` возвращает измерения за указанный диапазон.
  Передавайте `signal` в `fetch`, чтобы отменять запрос при размонтировании или повторе.
- `subscribe(onSamples, onError)` передаёт пакеты измерений и возвращает функцию,
  закрывающую WebSocket/SSE и удаляющую обработчики. При ошибке вызывайте `onError`.
- Время — Unix timestamp в **миллисекундах**, загрузка — число от 0 до 100.
  `null` означает пропущенное измерение и разрыв линии.
- История может быть неотсортированной. Поток должен идти по возрастанию времени;
  повтор последней временной отметки заменяет значение. Более старые точки потока,
  будущие отметки и некорректные значения отбрасываются.

Подписка открывается до загрузки истории. Измерения, поступившие во время запроса,
объединяются с историей; при совпадении отметок приоритет у потока.

Буфер хранит последние сутки, максимум 100 000 точек. При превышении лимита
вытесняются самые старые точки. Лимит защищает память, в том числе в фоновой вкладке;
для большей плотности измерений за сутки увеличьте `MAX_POINTS` или агрегируйте данные
в источнике. Отрисовка ограничена десятью обновлениями в секунду, а данные принимаются
независимо от отрисовки. Применение новой временной шкалы использует публичный config
YAGR 5 и обновление серии по id: полная замена через перегрузку `setSeries(timeline, …)`
пересоздала бы uPlot.

`npm test` проверяет буфер, гонку истории с потоком, пакетные обновления, масштаб,
темы, обработку ошибки и очистку ресурсов. Canvas-движок в тестах жизненного цикла
заменён заглушкой; эти тесты не измеряют FPS и не проверяют визуальное качество.
`npm run build` выполняет TypeScript-проверку и production-сборку.

Для визуальной проверки откройте страницу в светлой и тёмной теме, на ширине около
375 и 1400 px: проверьте контраст, отсутствие горизонтального переполнения,
подсказки, выделение диапазона и сброс масштаба. Отдельно проверьте состояния
загрузки, пустой истории и ошибки на реальном источнике.
