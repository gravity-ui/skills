# Мониторинг CPU

```sh
npm install
npm run dev
npm test
npm run build
```

`src/CpuChart.tsx` — адаптивный интерактивный график на `@gravity-ui/yagr`.
Он получает текущую светлую/тёмную тему из Gravity UI. Поддерживаются подсказки,
увеличение выделением, сброс масштаба, интервалы 1/6/24 часа и пауза отображения.
Во время паузы получение данных продолжается.

В приложении явно обозначен **демонстрационный источник**: около 43 200 точек
за сутки, новое измерение каждые 2 секунды. Реального API метрик в проекте нет.

Для подключения API реализуйте `CpuSource` из `src/cpu-data.ts` и передайте его
стабильный экземпляр в `<CpuChart source={source} />`:

- `loadHistory(signal)` возвращает историю за сутки и должен учитывать AbortSignal.
- `subscribe(onSamples, onError)` подключает WebSocket/SSE или другой транспорт
  и возвращает функцию освобождения соединения и обработчиков.
- Время — Unix milliseconds; значения — 0–100 или `null` для отсутствующих измерений.
- История и поток должны быть упорядочены по времени. Повтор последней временной
  метки обновляет её значение; более старые, будущие и некорректные точки отбрасываются.
- Подписка открывается до загрузки истории; поступившие во время загрузки точки
  временно сохраняются и объединяются с историей после ответа.

История хранится в кольцевом буфере за последние 24 часа, максимум 100 000 точек.
При превышении лимита удаляются самые старые точки; для источников с большей
частотой нужна предварительная агрегация или согласованное увеличение лимита.
Обновления объединяются до четырёх раз в секунду. Большие массивы не создают
DOM-элементы: Yagr рисует на Canvas. Для простой серии без преобразований
обновляется публичный `uplot.setData`, с синхронизацией данных Yagr; Canvas и
выбранный пользователем масштаб сохраняются. В скрытой вкладке отрисовка
приостанавливается, а память буфера остаётся ограниченной.

Размер отслеживает ResizeObserver с объединением вызовов через requestAnimationFrame.
При размонтировании отменяются запрос истории, подписка, интервал, кадры и обработчик
видимости; observer отключается, вызывается `Yagr.dispose()`.

Проверки: Vitest тестирует буфер, пакетные обновления, тему, масштаб, паузу,
состояния загрузки/пустых данных/ошибки и очистку в React Strict Mode.
Yagr в компонентных тестах заменён заглушкой: тесты не измеряют FPS и не проверяют
реальное отображение Canvas. `npm run build` запускает проверку TypeScript и Vite.
Для ручной визуальной проверки: светлая/тёмная темы, ширина около 375 и 1400 px,
подсказки и выделение области на графике.
