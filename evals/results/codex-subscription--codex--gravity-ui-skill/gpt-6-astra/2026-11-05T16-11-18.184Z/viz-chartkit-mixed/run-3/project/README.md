# Спектр — виджет аналитики

`npm install` — установить зависимости. `npm run dev` — запустить приложение.
`npm run build` — проверить TypeScript и собрать production-версию.
`npx vitest run` — проверить согласованность временных рядов.

## Единый API

Настройка плагинов находится в `src/chartSettings.ts` и импортируется один раз в точке входа.

```tsx
import './chartSettings';
import {VisualizationWidget} from './components/VisualizationWidget';

<VisualizationWidget
  mode="sales" // или "monitoring"
  series={[
    {id: 'current', name: 'Текущий период', points: [{x: 1793836800000, y: 42000}]},
  ]}
  loading={false}
  onRetry={reloadData}
/>
```

`x` — Unix timestamp в миллисекундах; `y` — числовое значение.
`secondary` обозначает дополнительную серию. Для мониторинга серии должны иметь одинаковую временную сетку.
Дополнительные состояния: `loading`, `error`, пустой массив `series`.

Один `ChartKit` выбирает `gravity-charts` для продаж и `yagr` для мониторинга.
Официальные плагины используют `React.lazy`: production-сборка содержит отдельные динамические модули
`GravityChartsWidget` и `YagrWidget`, которые загружаются при первом открытии соответствующего режима.
Импорты типов не включают движки в начальный пакет.

Демонстрационные продажи фиксированы по 4 ноября 2026 года. Мониторинг генерируется с шагом 1 секунда
(до 10 800 точек на серию) и обновляется каждые 5 секунд. Исторические значения стабильны при обновлении.
Переключатель автообновления останавливает таймер. CSV содержит видимые серии выбранного периода.
Подключение реального backend не входит в демонстрацию: передайте его данные через `series`.

Визуальная проверка в браузере не выполнялась. Для приёмки проверьте светлую и тёмную темы,
ширины 375 и 1400 px, оба режима, а также состояния загрузки, ошибки и отсутствия данных.
