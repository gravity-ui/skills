# Пульс — виджет визуализации

Один виджет для продаж и плотных временных рядов мониторинга на Gravity UI.

```bash
npm install
npm run dev
npm test
npm run build
```

## Единый API

```tsx
import {VisualizationWidget} from './src/components/VisualizationWidget';
import type {VisualizationData} from './src/data';

const data: VisualizationData = {
  unit: '₽',
  series: [{
    id: 'revenue',
    name: 'Выручка',
    points: [
      {x: Date.UTC(2026, 9, 1), y: 61000},
      {x: Date.UTC(2026, 9, 2), y: 69000},
    ],
  }],
};

<VisualizationWidget
  mode="sales" // 'sales' | 'monitoring'
  data={data}
  comparison={true}
  grid={true}
  loading={false}
  error={undefined}
  onRetry={() => {/* повторный запрос к вашему источнику */}}
/>
```

Обёртка приложения должна содержать `ThemeProvider` и стили UIKit (см. `src/main.tsx` и `src/App.tsx`). Временные метки — миллисекунды UTC, отсутствующие значения — `null`. При выключенном сравнении отображается только первый ряд. Для мониторинга ряды автоматически выравниваются по общему отсортированному временному ряду; пропуски остаются `null`.

ChartKit регистрирует `GravityChartsPlugin` и `YagrPlugin` один раз на уровне модуля. Их рендереры используют `React.lazy`: Gravity Charts загружается для продаж, YAGR — при первом открытии мониторинга. Импорты типов не включают движки в начальный JavaScript. Сборка формирует `dist/.vite/manifest.json` для проверки динамических точек входа.

В интерфейсе используются воспроизводимые демонстрационные данные. Продажи: 7/30/90 дней, мониторинг: 1/6/24 часа с 2 880 точками на ряд. Автообновление мониторинга сдвигает окно каждые 5 секунд. Таймер очищается при отключении, смене режима и размонтировании. CSV содержит только выбранные для отображения ряды.

## Проверки

- `npm test`: периоды продаж, плотность и выравнивание мониторинга, сдвиг временного окна, экспорт пропусков и экранирование CSV.
- `npm run build`: TypeScript и production-сборка.
- Манифест проверен: оба рендерера — динамические точки входа, не входят в начальный граф статических импортов.

Браузерная проверка не выполнялась. TypeScript не проверяет компоновку и контраст. Для ручной приёмки: обе темы при ширине около 375 и 1400 px, переключение режимов, tooltip, zoom мониторинга, сравнение, CSV, а также состояния `loading`, `error` и пустого `data.series`.
