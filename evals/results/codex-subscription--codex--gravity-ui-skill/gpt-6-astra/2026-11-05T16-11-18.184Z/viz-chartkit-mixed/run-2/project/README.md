# Pulse — единый виджет визуализации

```sh
npm install
npm run dev
```

`VisualizationWidget` принимает одинаковый формат данных для продаж и мониторинга:

```tsx
import {VisualizationWidget} from './src/VisualizationWidget';
import type {VisualizationData} from './src/data';

const data: VisualizationData = {
  unit: '₽',
  series: [{
    id: 'revenue',
    name: 'Выручка',
    points: [
      {timestamp: Date.UTC(2026, 10, 1), value: 48000},
      {timestamp: Date.UTC(2026, 10, 2), value: 53000},
    ],
  }],
};

<VisualizationWidget mode="sales" data={data} showComparison />;
```

- `mode`: `sales` для Gravity Charts, `monitoring` для YAGR.
- `data`: ряды с метками времени в миллисекундах UTC и числовыми значениями. Точки упорядочены по времени; для нескольких рядов мониторинга нужны одинаковые временные сетки. Демонстрационный мониторинг показывает загрузку CPU на шкале 0–100%.
- `showComparison`: показывать ряды с `comparison: true` (по умолчанию `true`).
- `loading`, `error`, `onRetry`: состояния загрузки, ошибки источника и повторного запроса.

Два плагина регистрируются один раз через `settings.set`. Их встроенные `React.lazy`-рендереры загружают соответствующий движок при первом открытии режима. Импорты типов движков удаляются при сборке. Обёртка использует один `<ChartKit>` и преобразует общий формат в конфигурацию выбранного плагина.

В интерфейсе есть выбор периода, сравнение продаж, автообновление мониторинга каждые 10 секунд, экспорт отображаемых рядов в CSV и переключение темы. Все данные демонстрационные: продажи фиксированы по 5 ноября 2026 года, мониторинг генерируется для текущего времени. Для реального источника передайте его данные через API виджета.

Проверки:

```sh
npm test
npm run build
```

Сборка проверяет TypeScript и автоматически подтверждает по Vite manifest, что оба рендерера — независимые динамические чанки, отсутствующие в статических зависимостях входного файла.

Визуальная проверка в браузере не выполнялась. Ручная проверка: обе темы, ширины 375 и 1400 px, переключение режимов и периодов, подсказки, масштабирование мониторинга, загрузка, пустые данные и ошибка источника. TypeScript и проверка чанков не подтверждают качество вёрстки и контраст.
