# Pulse — единый виджет визуализации

React + TypeScript + Gravity UI. Один `VisualizationWidget` принимает общий формат данных и выбирает движок по `mode`:

- `sales`: линейный SVG-график Gravity Charts;
- `monitoring`: плотный временной ряд YAGR с масштабированием выделенной области.

ChartKit регистрирует оба плагина один раз. Каждый плагин использует `React.lazy`: код движка и его CSS загружаются при первом открытии режима. Статические импорты типов не попадают в runtime.

## Запуск

```sh
npm install
npm run dev
```

```sh
npm run build
npx vitest run
```

## API

```tsx
import {VisualizationWidget} from './src/VisualizationWidget';

<div style={{height: 320}}>
  <VisualizationWidget
    mode="sales" // либо "monitoring"
    unit="₽"     // для мониторинга, например, "мс"
    series={[
      {
        name: 'Выручка',
        points: [
          {timestamp: Date.UTC(2026, 9, 1), value: 54000},
          {timestamp: Date.UTC(2026, 9, 2), value: 65000},
        ],
      },
    ]}
  />
</div>
```

`timestamp` — UTC Unix timestamp в миллисекундах. Передавайте точки по возрастанию времени; серии мониторинга должны иметь одинаковую временную сетку. Дополнительные свойства: `loading`, `error`, `onRetry`. Пустой массив отображает состояние без данных. Ошибка загрузки движка предлагает перезагрузку страницы для повторного получения динамического чанка.

UI содержит периоды, выбор метрики и группировки, сравнение, CSV с UTF-8 BOM, разворачивание графика, светлую/тёмную тему и автообновление мониторинга. Все данные демонстрационные, backend не подключён. Переключение на продажи или отключение автообновления освобождает интервал.

TypeScript и тесты расчётов не заменяют визуальную проверку. Перед публикацией проверьте обе темы, ширины 375/1400 px, состояния загрузки, ошибки и пустых данных в целевом браузере.
